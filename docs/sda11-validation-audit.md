# SDA 11 bidirectional validation audit

This matrix is the working evidence record for the two independent reviews
required by SDA 11. `PASS` means the implementation is connected to an
executed test. `LIMIT` records a deliberately narrower claim. Databricks rows
refer to the `sda` profile and the live bundle run; no internal run IDs are
part of the article.
